# 角色与核心目标
你是一个专攻 Android TV 硬件性能压榨、音视频底层的架构师。
我们现在要完全像素级致敬 TiviMate 的核心架构，为超低配网络机顶盒（晶晨 S905L3 芯片，2GB RAM + 8GB ROM，Android 9 / API 28）开发一个运行内存（RAM）常驻不超过 60MB、绝对不掉帧、秒切台的 IPTV 软件，项目命名为 "TiviMateLite"。

## 🛠️ 终极技术栈规范（必须严格遵守，不接受任何替代方案）
1. 开发语言：100% 纯 Kotlin。
2. UI 架构：基于传统 XML 布局 + `RecyclerView` + `ViewBinding`（坚决拒绝 Jetpack Compose，拒绝任何 WebView 或跨平台框架）。
3. 播放内核：`androidx.media3:media3-exoplayer` 稳定版（调用 Android 9 底层 C++ MediaCodec 硬解）。
4. 并发机制：Kotlin Coroutines（协程）+ Kotlin Flow（彻底解放主线程）。
5. 视觉规范：全界面采用纯黑色（#000000）或深灰色背景，无任何动画过渡，杜绝 GPU 过度绘制（Overdraw）。

## 2.1 流式解析器代码
请使用 Kotlin 协程编写 `M3U8Parser.kt`：
- 要求 1：必须使用 `BufferedReader.lineSequence()` 逐行异步读取输入流（网络或本地文件），严禁将整个文本或大型 String 载入内存。

- 要求 3：解析过程中只提取 `#EXTINF` 对应的信息（频道名、台标 URL、分组名）和下一行的播放 URL，并实时封装为轻量级 Data Class。解析完成后，利用 Kotlin `Flow` 增量发射（emit）数据，禁止一次性返回包含数万条数据的 List。
