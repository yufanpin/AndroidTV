=== Important Working Practices ===
1. ADB over TCP drops after ~3 minutes of inactivity (even on wired Ethernet).
   Solution: Send keepalive every 5s: `adb shell echo alive > /dev/null`
   All long-duration tests MUST include this keepalive.

2. PowerShell $pid is a read-only automatic variable. NEVER assign to $pid.
   Use $currentPid, $procId, or any other name instead.

3. The app has FileLogStore that writes to context.cacheDir/tivimate_diag.txt.
   This file persists across ADB disconnects. Pull via:
   `adb shell cat /data/data/com.tivimatelite/cache/tivimate_diag.txt`

4. Heartbeat logs every 10s (HEARTBEAT_INTERVAL_MS = 10000L).
   Use this to confirm the app is alive when ADB is disconnected.

5. Pushing to test branch requires manual CI dispatch:
   `gh workflow run "Android CI" --ref test`
