=== Important Working Practices ===
1. ADB over TCP drops after ~3 minutes of inactivity (even on wired Ethernet).
   Solution: Send keepalive every 5s: `adb shell echo alive > /dev/null`
   All long-duration tests MUST include this keepalive.

2. PowerShell $pid is a read-only automatic variable. NEVER assign to $pid.
   Use $currentPid, $procId, or any other name instead.

3. The app has FileLogStore that writes to context.cacheDir/tivimate_diag.txt.
   This file persists across ADB disconnects. Pull via:
   `adb shell cat /data/data/com.tivimatelite/cache/tivimate_diag.txt`

4. Heartbeat logs every 10s (HEARTBEAT_INTERVAL_MS = 10000L).
   Use this to confirm the app is alive when ADB is disconnected.

=== LATEST CHANGES (2026-06-05) ===
All changes below are UNCOMMITTED. They implement P0-P5 improvements
identified by comparing mytv-android vs AndroidTV.

[P0] Smart source host memory (PlayableHostStore)
- NEW: app/src/main/java/com/tivimatelite/player/PlayableHostStore.kt
  SharedPreferences-based storage that remembers which domain-level hosts
  have proven playable. Key functions: addHost(), removeHost(), getHosts().
  `extractHost()` extracts domain from URL (e.g. "stream.example.com").
- ChannelSwitcher now accepts getPlayableHosts lambda; findPreferredSourceIndex()
  picks remembered-good host; playNextSourceForCurrentChannel() prefers
  un-attempted hosts from the remembered set.
- MainActivity: on STATE_READY → PlayableHostStore.addHost(), on PLAYER_ERROR
  → PlayableHostStore.removeHost().

[P1] Playback error resilience (PlayerManager)
- BEHIND_LIVE_WINDOW: seekToDefaultPosition() + prepare() on error.
- PARSING_CONTAINER_UNSUPPORTED: content-type retry chain
  auto (C.CONTENT_TYPE_OTHER) → HLS → Progressive (OTHER),
  tracked per-URL via contentTypeAttempts map.

[P2] 15s load timeout (ChannelSwitcher)
- NEW: CHANNEL_LOAD_TIMEOUT_MS = 15000L constant.
- startLoadTimeout() launches coroutine that fires after 15s;
  cancelLoadTimeout() cancels on STATE_READY.
- Cancellation wired in MainActivity's onPlaybackStateChanged(STATE_READY).

[P3] SurfaceView instead of PlayerView
- activity_main.xml: replaced PlayerView+id with SurfaceView+id=playerSurface.
- MainActivity: player.setVideoSurfaceView(binding.playerSurface) instead of
  PlayerView binding, no more setShutterBackgroundColor. Focus→playerSurface.

[P4] EXTENSION_RENDERER_MODE_ON
- PlayerManager.buildPlayer(): DefaultRenderersFactory with
  setExtensionRendererMode(EXTENSION_RENDERER_MODE_ON).
- Degrades gracefully if no ffmpeg extension is installed.

[P5] Decoder info (PlayerManager)
- NEW: DecoderMetadata data class tracks video/audio mime, resolution,
  frame rate, bitrate, decoder names.
- NEW: decoderInfoListener (AnalyticsListener) collects onVideoInputFormatChanged,
  onVideoDecoderInitialized, onAudioInputFormatChanged, onAudioDecoderInitialized.

Additional changes:
- HTTP connect timeout: 5s→15s, read timeout: 12s→20s (P0-like tolerance).
- setKeepPostFor302Redirects(true) for redirect-following compatibility.
- build.gradle.kts: added media3-exoplayer-rtsp and media3-decoder deps.
