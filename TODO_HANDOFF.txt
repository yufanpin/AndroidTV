=== Important Working Practices ===
1. ADB over TCP drops after ~3 minutes of inactivity (even on wired Ethernet).
   Solution: Send keepalive every 5s: `adb shell echo alive > /dev/null`
   All long-duration tests MUST include this keepalive.

2. PowerShell $pid is a read-only automatic variable. NEVER assign to $pid.
   Use $currentPid, $procId, or any other name instead.

3. The app has FileLogStore that writes to context.cacheDir/tivimate_diag.txt.
   This file persists across ADB disconnects. Pull via:
   `adb shell cat /data/data/com.tivimatelite/cache/tivimate_diag.txt`

4. Heartbeat logs every 10s (HEARTBEAT_INTERVAL_MS = 10000L).
   Use this to confirm the app is alive when ADB is disconnected.

   mechanism (300s timeout), which is very conservative.
 Next step:
   1. Verify if this affects user experience (does stalling actually happen?).

=== Architecture Notes ===
- PlayerManager.kt: Singleton ExoPlayer (object), reflection-based audio params.
- MainActivity.kt: All key handling, source switching, ready-stall watch.
- FileLogStore.kt: File-based logging (not logcat-dependent).
- AppLogStore.kt: In-memory ring buffer for web admin log viewer.
- LocalAdminServer.kt: NanoHTTPD-based web admin (port 5220).
- PlaylistStore.kt: Playlist source management (local/remote/custom).
- RemotePlaylistRepository.kt: Remote source detection and fetching.
- M3U8Parser.kt: Streaming M3U8 parser.
- PlaybackHistoryStore.kt: Last channel persistence.
